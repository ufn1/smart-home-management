# Негізгі сценарий: жарықты қашықтан қосу/өшіру

**Actor:** пайдаланушы (үй иесі немесе рұқсаты бар отбасы мүшесі).  
**Алдын ала шарт:** пайдаланушы жүйеге кірген, жарық құрылғысы жүйеде тіркелген.  
**Негізгі нәтиже:** жүйе жарықтың жаңа күйін сақтап, қолданбаға көрсетеді.

## Негізгі ағын
1. Пайдаланушы мобильді қосымшаны ашады.
2. Құрылғылар тізімінен ақылды жарықты таңдайды.
3. Жүйе құрылғының күйі мен пайдаланушы рұқсатын алады.
4. Пайдаланушы «Қосу» немесе «Өшіру» командасын жібереді.
5. Сервер пайдаланушы рұқсатын тексереді.
6. Рұқсат болса, сервер командасын ақылды жарыққа жібереді.
7. Құрылғы нәтижені қайтарады.
8. Сәтті болса, сервер жаңа күйді деректер базасына сақтап, қолданбаға хабарлайды.

## Баламалы ағындар
- **Рұқсат жоқ:** сервер пәрменді орындамайды; қолданба қате туралы хабарлайды.
- **Құрылғы қолжетімсіз / пәрмен сәтсіз:** жаңа күй сақталмайды, қолданбада қате көрсетіледі.

## Диаграммалар
Activity пайдаланушы мен жүйенің әрекеттерін және екі тармақталуды көрсетеді. Sequence сол сценарийдің қолданба, API, деректер базасы және құрылғы арасындағы хабар алмасуын көрсетеді.
