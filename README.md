# Smart Home Management System — Ақылды үйді басқару жүйесі

**Орындаған:** Рысбай Аманжан  
**Тобы:** ИСк-24-1а  
**Диплом тақырыбы:** Ақылды үй жүйесін әзірлеу

## Жоба туралы
Smart Home Management System — үйдегі ақылды құрылғыларды телефон немесе веб-интерфейс арқылы басқаруға арналған ақпараттық жүйе. Жүйе жарықты қашықтан қосып-өшіруге, құрылғылар күйін тексеруге және орындалған командалардың нәтижесін көруге мүмкіндік береді. Бұл жоба үй иелеріне күнделікті басқаруды ыңғайлы етуге арналған.

## Мақсаты
Үй құрылғыларын қауіпсіз әрі ыңғайлы қашықтан басқаруға арналған ақпараттық жүйе әзірлеу.

## Пайдаланушылар
- **Үй иесі:** құрылғыларды қосады/өшіреді және олардың күйін қарайды.
- **Отбасы мүшесі:** берілген рұқсат аясында құрылғыларды басқарады.
- **Әкімші:** пайдаланушылар мен құрылғылардың қолжетімділігін баптайды.

## Талаптар
1. Пайдаланушы логин мен құпиясөз арқылы жүйеге кіреді.
2. Пайдаланушы өзіне қолжетімді ақылды құрылғылар тізімін көреді.
3. Пайдаланушы жарықтың ағымдағы күйін (қосулы/өшірулі) қарайды.
4. Пайдаланушы жарықты қосу немесе өшіру командасын жібереді.
5. Жүйе пайдаланушының құрылғыны басқаруға рұқсатын тексереді.
6. Сервер команданы ақылды құрылғыға жеткізіп, жауапты қабылдайды.
7. Жүйе команда сәтті орындалса, жаңа күйді деректер базасына сақтайды.
8. Жүйе команданың сәтті орындалғаны не қате болғаны туралы хабарлайды.

## Негізгі сценарий
**«Жарықты қашықтан қосу/өшіру»** — пайдаланушы қосымшада жарық құрылғысын таңдап, команда жібереді; сервер рұқсатты тексеріп, құрылғыға команда жолдайды; нәтиже қосымшада көрсетіледі.

## Жоспарланған технологиялар
- Клиент: веб немесе мобильді қосымша
- Сервер: REST API
- Деректер базасы: пайдаланушылар мен құрылғылар күйін сақтау
- IoT: Wi-Fi арқылы басқарылатын жарық контроллері

> Бұл репозиторий — дипломдық жобаның негізгі репозиторийі. Алдағы апталарда басқа диаграммалар мен бағдарламалық код қосылады. Қазіргі кезеңде жүйенің мінез-құлқы модельденген, жұмыс істейтін құрылғы интеграциясы әлі іске асырылмаған.
